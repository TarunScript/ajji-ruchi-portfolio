# Ajji Ruchi & Allied Brands — Product Portfolio & Pitch Showcase
> **50 Years of Authentic South Indian Recipes — Grandmother's Kitchen, Now Packed For Yours.**  
> *Flagship Brand of M.G. Bannishetty Foods & Beverages*

---

## 🌟 Overview
**Ajji Ruchi** is a traditional homemade food enterprise inspired by 50 years of generational culinary heritage from Karnataka. This modern web application serves as the official digital showcase, pitch presentation portal, and interactive product catalog for meetings with retailers, supermarkets, modern trade distributors, export partners, and direct consumers.

---

## 🚀 Key Features

### 1. Boardroom Pitch Deck Mode
- Full-screen meeting presentation overlay accessible with a single click.
- 6 boardroom slides covering:
  1. *Executive Overview & Legacy*
  2. *Market Opportunity & Consumer Shift to Clean-Label Regional Foods*
  3. *30+ Market-Ready SKUs*
  4. *Holistic Wellness (Ajji Ruchi Nutrition + OPPER Skincare + GEET Gifting)*
  5. *Founder Leadership & Pedigree*
  6. *Omnichannel Scaling & Unit Economics*
- Keyboard navigable (`←`, `→`, `Space`, `Esc`) with full-screen support.

- Real-time search by English name, Kannada name, or ingredients.
- Dynamic category filters:
  - **⭐ Bestsellers**
  - **Signature Masalas** (Special Sambar, Rasam, Palya, Garam Masala)
  - **Kitchen Essentials** (Pure Byadgi Chilli, Coriander, Turmeric)
  - **Rice & Bath Powders** (Mysore Vangi Bath, Bisi Bele Bath, Tomato Bath, Puliyogare)
  - **Millet & Instant Mixes** (Ragi Idli, Multi-Millet Idli, Navane Bisibelebath, Navane Pongal, Dosa, Rave Idli)

- Native HTML `<dialog>` quick specs modal with roasting notes, ingredients, dietary badges, and pack sizes.

- **Frontend**: Semantic HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3.

- **Typography**: Cinzel, Cinzel Decorative, Outfit, Plus Jakarta Sans, Tiro Kannada.

## 📦 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/TarunScript/ajji-ruchi-portfolio.git
   cd ajji-ruchi-portfolio
   ```
2. Start any local static file server:
   ```bash
   python3 -m http.server 3000
   ```
3. Open `http://localhost:3000` in your web browser.
